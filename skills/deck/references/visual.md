# Visual

Used in step 6. The visual starts from one concept that organizes how the whole deck looks, because a slide that solves its visual alone turns the deck into a collage.

## The guide

The identity material the user brought (a visual guide, a brand manual, a template, decks they liked) binds every concept: its colors, fonts and mandatory elements. The concepts then differ in how they draw the forms below (style, composition, a guiding image), not in the forms or the brand. Without such material, ask in the concepts message whether there is one, and give each concept its own palette and font pairing.

## Forms

List the kinds of information the slides carry and give each the form that shows it at a glance, chosen by what the slide's title claims, not by the shape of the data:

| The slide shows… | Form |
|---|---|
| A sequence of steps or stages | A flow: steps linked by arrows |
| A comparison, or a before and after | Side by side in the same layout, the difference highlighted |
| A set, its size or a part of it (people, pieces, "62% of respondents", "3 in 10") | Dots, one per unit or per a stated number of units, the part the title claims highlighted |
| Groups inside groups | Nested circles |
| How something works (who does what) | The actors as shapes, the actions as labeled arrows |
| Items that serve goals (deliverables, fronts) | A map: each item placed under the goal it serves |
| Change over time | A line, with the events marked on it |
| Amounts across categories | Sorted bars, the one the title claims highlighted |
| One number that matters | The number large, with what it compares to |
| An abstract idea (a vision, a goal, a risk) | A concrete metaphor, within the concept |

The same kind of information takes the same form everywhere in the deck, the same color always means the same thing, and one highlight color marks what each title claims. Layouts vary with each slide's job, within the concept.

## Concepts

Propose two or three, one recommended. For each:
- a short name and the idea in one sentence (to calibrate, not to copy: "the deck as a route map, each part a stop on the way"; "only simple geometric shapes, so the data becomes shape"; "a sober system of color and grid");
- how it draws each kind of information in this deck, using the forms above;
- palette and fonts, from the guide when there is one;
- why it serves the central idea, and its risk.

Before recommending one, check that it works on the densest slide, fits the guide and can be built with what this session can make slides with: read `build.md`, Choosing how to build, to find out. For a sober deck read alone, a discreet concept usually works better than a strong metaphor.

## Illustration plan

Once the user picks a concept, plan every slide:

```
[N]. [Title]
  Form: … · Shows: [the exact content or data] · Highlight: …
  Text change (proposed): [approved text] → [new text] — [why]
```

Each illustration shows what its title claims; one that only fills the slide goes. A text change line appears only when the illustration needs it (a label in place of a sentence, words the drawing now carries) and stays marked until the user approves it, since the text was closed at Gate 1.

## Sample

With the plan, draw two or three slides in the concept, the densest among them, at low fidelity: inline, when the session can show an image or a page; otherwise as a precise description of each. The sample tests the concept and the plan, not the deck, so it is a sketch, not the built file.
