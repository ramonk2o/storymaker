# Handoff

Used to bring the delivery options with the results of the checks (Phase 2) and to deliver. The lesson is finished; what is left is getting it where it will be used, in a form the user can still edit.

## Choosing how to deliver
1. **Look at what this session can do right now** to deliver a document: editable document artifacts, skills that build document files, connectors to apps where the lesson will live (a document editor, a course platform, a wiki), and a Markdown file or plain text in the reply. Offer only what is actually available; never assume a tool exists.
2. **Judge each option against this lesson,** from what the map says about the format: who teaches it and edits it afterwards, whether learners get a copy, and whether headings, tables and the teacher blocks have to survive the trip.
3. **Present two to four viable options,** numbered, each with one pro and one con for this lesson, and recommend one with the reason. In the light path, one line per option. The Markdown file always exists as a fallback; if it is the only option, deliver it without listing options.

## Delivering
- The Lesson map is the specification: moving the lesson to another format doesn't reword it.
- Outside the lesson, deliver in a few lines: what changed from the map, if anything; open items marked `[TO CONFIRM]`; the fact check (how many facts, what changed) and the cold learner (what failed, what was fixed), one line each, or "not run".
- When learners get their own copy, offer a learner version without the teacher blocks, keeping the Answers section.
- After moving the lesson, check that headings, tables, the teacher blocks and the source list survived.
- Offer, in one line, to keep the approved map next to the lesson: it is the quickest way to rework or extend it later, or to plan the next lesson of a series.

## Into slides
- **If the session can load the deck skill,** offer in one line to turn the lesson into slides with it. When the user accepts, hand the deck the lesson file and the approved map: the deck starts without its offer, and treats the content as settled as `references/lesson-file.md` says.
- **If it can't,** say in one line that the file is ready to be used as the material for a presentation, with the key ideas as slide titles.
